1 · Human sets the policy

The agent never sees a full-access key. These limits live in the vault, not in the prompt.

2 · Agent tries to spend

The agent proposes a payment. SpendGuard simulates, then accepts or rejects. A reject leaves the vault unchanged.

Uses a deterministic offline fallback unless an OpenAI-compatible API key is set on the server.
